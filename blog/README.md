# Pixelverse Blog

Blog posts about pixel art, game development, and using Pixelverse.

## Post Format

All posts use Markdown with YAML frontmatter:

```yaml
---
title: "Your Post Title"
slug: url-friendly-slug
date: YYYY-MM-DD
author: Author Name
tags: [tag1, tag2]
description: "Brief description for SEO and previews"
featured: true/false (optional)
---
```

## Naming Convention

Files should be named: `YYYY-MM-DD-slug.md`

Example: `2025-01-30-magic-of-constraint.md`

## Content Guidelines

- Write in a friendly, approachable tone
- Include practical tips and examples
- Reference Pixelverse features when relevant
- Use code blocks for color values and technical details
- Include calls-to-action to encourage engagement
